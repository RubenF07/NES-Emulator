## NES Emulator

A basic Nintendo Entertainment System hardware emulator implemented in Rust.

- **Constructed with guidance from:** [Writing NES Emulator in Rust](https://bugzmanov.github.io/nes_ebook/chapter_1.html)


## Build & Run

- Add NES V1 ROM file location to `main.rs` in the `// load program` section.

```bash
cargo run
```
